# Local dataset

The PaySim transaction CSV is intentionally not included in this repository. Obtain it from a source whose terms permit your use and save the full dataset as `transactions.csv` in this directory before running `preprocessing_pipeline.ipynb`.

The Kaggle listing for [Synthetic Financial Datasets For Fraud Detection](https://www.kaggle.com/datasets/ealaxi/paysim1) identifies the dataset as CC BY-SA 4.0. Attribute Edgar Lopez-Rojas and the dataset source, link to the license, and describe changes when sharing copies or adaptations.
